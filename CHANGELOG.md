# Changelog

## 0.6.0

- New Opportunities tab (renamed "Deals" in the tab bar): with the free
  desktop app installed, ranks what to disenchant or sell at the AH, synced
  automatically whenever your gear, prices or disenchant data change.
- Roster list redesigned into clean columns, left to right: class icon,
  name, level, professions (up to 4 icons, primary and secondary), RXP%,
  gold and mail.
- Rested XP now estimates every character's current rest from time since
  their last logout, instead of only showing whoever's currently logged in.
- Window is resizable (drag the bottom-right corner), and the character
  list/detail split can be dragged too — both remembered next time.
- Fixed: rested XP could get reset to 0 on logout instead of keeping the
  value tracked during play.
